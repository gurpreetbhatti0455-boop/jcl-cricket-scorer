Instructions
1. Tap New Match to start a fresh match.
2. Every match gets its own unique Match ID automatically. Enter the match country, state and city/ground for the broadcast header.
3. Your score is saved against that same ID and appears in Match History.
4. Use Match History to open a previous single match, resume it, or copy its overlay link.
5. Use Multiple Matches when you want to score several matches with a shared team list. End the session to finalize its points table.
6. For a live stream, copy the match Overlay Link and add it in PRISM Live Studio.

Old matches are no longer shown in a separate Live Matches list. Their saved records remain in Match History.
